# Car'Ess website v1

Files:
- index.html — luxury homepage
- shop.html — store/collection page with filters
- product.html — product detail template
- about.html — brand story
- journal.html — editorial page
- contact.html — contact page
- css/style.css — complete design system
- css/animations.css — motion/reduced-motion layer
- css/responsive.css — responsive extension file
- js/app.js — cart, localStorage, drag-and-drop, reveal and hero glow
- js/cart.js, dragdrop.js, animations.js — reserved extension modules
- assets/logo.svg — original Car'Ess logo
- assets/images — supplied product images
- assets/brands — supplied brand logos

Important: this is a front-end prototype. It does not process real payments, orders, taxes, delivery or age verification. Connect those before launch and replace placeholder contact information.
